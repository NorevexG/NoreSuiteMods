This namespace is reserved for direct resource-pack overrides for Retro Damage Indicators' HUD textures.

The selectable silver, platinum, and brown themes are stored under
assets/norestages_rdi_compat/textures/gui/themes and selected by config instead of direct override.

Override candidates from the RDI jar:
- damage_indicator.png
- damage_indicator_background.png
- damage_indicator_health.png
